About Me

I'm a Computer Science student at Kahuta Institute of Space & Technology, passionate about building software that is both intelligent and practical.

My main focus is .NET desktop development using C# and WinForms, where I've built AI-powered tools like a real-time language translator. I'm equally comfortable on the mobile side, developing Android applications with Java and Kotlin.

Beyond desktop and mobile, I love crafting interactive experiences — my 3D Crystal Collector game and full-stack Library Management System with Flask & MongoDB show my range across graphics, game dev, and web backends.

I believe great software solves real problems — that's why I gravitate toward projects that blend AI, clean architecture, and thoughtful UX. Outside coding, I'm exploring Docker, REST APIs, and GitHub Actions.
